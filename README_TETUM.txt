SISTEMA RECEITA DIGITAL PARA FARMACIA
=====================================

Sistema demonstrasaun ba rejistu no arkivu receita médica.
La halo diagnóstiku, la rekomenda remédiu, no la substitui receita válida.
Dose, remédiu no instrusaun tenke kopia husi receita husi profisionál saúde autorizadu.
Farmaséutiku tenke halo verifikasaun antes entrega remédiu.

OINSÁ RUN IHA WINDOWS:
1. Extract ZIP.
2. Loke pasta Sistema_Receita_Digital_Farmacia.
3. Klik-rua run_app.bat.
4. Hein Streamlit instala.
5. Browser loke iha http://localhost:8501.

FICHEIRU:
- app\app.py: sistema.
- receitas.db: kria automaticamente bainhira sistema hahú.
- requirements.txt: biblioteka.
- run_app.bat: komandu atu loke.

PRIVASIDADE:
Dadus pasiente mak dadus sensível. Uza deit iha ambiente autorizadu,
proteje komputadór ho senha, limita asesu, halo backup seguru no tuir lei
no regra privasidade saúde iha ita-nia fatin. Versaun demonstrasaun ida-ne'e
seidauk iha login, enkripsaun, assinatura dijitál ka audit trail.
